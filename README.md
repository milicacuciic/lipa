# Салаш Липа — концептуални сајт

Изоставни бренд (измишљен салаш) направљен као пример дизајна. Сви називи, контакти и фотографије су илустративни.

Статички сајт (HTML, CSS, мало JavaScript-а). `index.html` почетна, `jelovnik.html` јеловник, `galerija.html` галерија; `m/` су исте странице за телефон.

Објављивање: ставити садржај фасцикле у корен GitHub repository-ја, па Settings → Pages → Deploy from a branch → `main` / root.
